# Textolite

App Android leve para converter fotos (texto impresso e manuscrito) em **.md**, **.fodt** e **.pdf**.

- **Offline por padrão** (ML Kit, roda no celular, sem internet).
- **IA opcional** para melhor leitura de escrita à mão, tabelas e esquemas: Google Gemini ou qualquer serviço compatível com o formato OpenAI (OpenRouter, Groq, OpenAI...). A chave de API é digitada no app e fica criptografada no aparelho; nada de chave no código.

## Instalar

Baixe `textolite.apk` na página de [Releases](../../releases/tag/apk-latest) pelo celular e abra o arquivo (o Android pedirá para permitir a instalação de apps desta fonte).

O APK é gerado automaticamente pelo GitHub Actions a cada atualização do código.
